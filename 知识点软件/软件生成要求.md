# 总述  
你需要编写的是一个类思维导图软件，它的名字是“the sea of knowledge”。该软件的代码主要为C语言，但可随意使用其它语言作为补充。 
你拥有很大权限，可以自由调用软件、查看文件来达到最终结果。
最终你需要给出软件本体,云端建立与处理这些文件以完成目的的方法，你服务的对象为电脑小白，因此需详细介绍步骤。
该类思维导图软件具有现代化UI，功能大致为“知识点”的创建、查看、编写、删除；思维导图的展示；“知识点”的收纳与整理；“知识点”的云端上传与下载。  
由于本人是中国人，软件应原生支持UTF-8汉语，包括软件内部的汉语，以及支持布置在含有汉语的目录等。软件还应支持emoji的显示。
下面将详细介绍各个板块的具体要求。  
# 现代化UI  
软件应当拥有扁平化现代风格UI，使用如Vlukan、OpenGL等API来达成此效果。  
软件应拥有内部窗口，以方便多个知识点和思维导图的查看。
显示知识点时，正文显示应占窗口的较大区域，但需留出区域显示前后相关知识点的名称与关系以及该知识点的名称与编号。（“正文”“前相关”“后相关”等概念在“‘知识点’的创建、查看、编写、删除”部分会进行介绍），需要留有“修改”按钮，点击该按钮进入知识点编写模式，还需要留有“思维导图”按钮，点击来显示与该知识点相关的思维导图。  
软件修改时正文及正文预览部分应占用较大区域，但知识点标题、编号、前后相关知识点（名称、编号、与该知识点）也应显示。
软件右上角拥有设置emoji表情，点击可进入设置界面。尤其注意设置内需拥有退出按钮，退出时会释放软件所有内存。软件可随意改变大小（窗口尺寸可以任意调节且内容相对位置不会改变），且刷新率可以在设置中更改。  
软件首页应当拥有一个搜索框来搜索需要打开的知识点，还应当拥有位置来写自己的电子签名（可更换字体），电子签名在设置进行修改。 
# “知识点”的创建、查看、编写、删除  
“知识点储存文件格式讲解.md”已一并发送给你，这是“知识点”文件的结构，对“知识点”的一切操作均需遵循此结构。尤其注意在编写时同时显示正文部分的原始内容和markdown预览内容，查看时直接将正文渲染好。知识点的创建有两种形式，可以选择创建知识点，在新建知识点的界面里写好知识点的名称，编号，然后进入知识点修改的界面；第二种形式是在思维导图界面点击新建知识点，写好名称和编号，随后可以正常进入知识点的方式进入该知识点，在知识点查看页面点击“修改”来进行填充。知识点修改界面应当显示并可以修改知识点名称，编号，正文以及正文的预览（预览严格对应正文部分，不可修改，且显示面积与正文相当，方便修改），前后相关知识点（存在删除按钮来删除部分废弃相关知识点）（添加时可以按照编号或名称搜素，也可自行输入）。在知识点编写页面存在“删除”按钮，点击并以气泡方式进行二次确认后，可删除该知识点。  
# 思维导图的展示  
思维导图只会显示知识点的名称，在知识点被选中后在额外的气泡中展示编号和部分正文的预览，在气泡的底部有一个跳转按钮，点击后在新窗口打开对应知识点界面。知识点间以可根据知识点间位置而自由调整的箭头相连，箭头指向“后相关”知识点。  
思维导图的显示有三种模式，显示模式在显示思维导图之前以气泡形式显示来进行选择：
- 第一模式为后延式，以被选择的知识点为开头，以后相关为方向展示思维导图。  
- 第二模式为周围式，以被选择的知识点为中心，显示其前相关与后相关知识点。  
- 第三模式为自由式，此时思维导图的角落会分别显示并可调节目前显示几层前/后相关知识点（前/后相关知识点的“层”概念：以该知识点为中心，显示该知识点的前方/后方知识点为第一层，显示其前方/后方知识点的前方的前方/后方知识点为第二层，以此类推。如三层前相关知识点即为显示该知识点（中心），其前相关知识点（第一层），其前相关知识点的前相关知识点（第二层）和其前相关知识点的其前相关知识点的前相关知识点（第三层））。  
  
思维导图显示界面还应拥有画笔按钮和一个清除按钮，画笔按钮点击后再点击知识点可对知识点进行“上色” ，颜色有红绿蓝三种，知识点默认颜色为蓝色。而清除按钮可以取消点击画笔按钮后光标点击知识点变色的性质。  
思维导图应拥有放大缩小功能来方便阅读，可以在思维导图显示中添加对应按钮来调节。    
# “知识点”的收纳与整理  
知识点应当被储存在软件同目录的子文件夹“知识点库”中。由于知识点可能含有图片，因此将知识点储存文件和图片分别放置在“知识点\储存文件”和“知识点\图片”中。为了方便实现知识点储存文件和图片的查找功能，将储存文件和图片的编号与名字以配置文件的方式储存在对应的文件夹中。当数据更新时（添加、更改、删除等），配置文件应随即更新。  
由于图片的特殊性，在知识点正文编写界面，拥有“插入图片”按钮，点击后子菜单显示“上传”和“搜素”，点击“上传”按钮可以将任意目录的图片上传到“知识点库”中，在存储该图片之前，应先询问该图片的名称及编号，得到具体信息后将图片重命名为“‘编号’+‘：’+‘名称’”，存储在“图片”文件夹中，然后返回到原来的子菜单。点击搜索时会出现气泡，气泡上方有搜索框，下方会显示对应图片的缩略图、编号与名称。选择好图片后，点击“确认”按钮，会在剪切板中添加对应的图片markdown引用形式，用户将其粘贴到正文即可使用。  
在开始界面存在“图片管理”按钮，点击会在新窗口显示图片管理面板。面板上方为搜索框，可进行编号与名称搜素。下方会显示相关图片的缩略图、编号与名称。单击图片可将其选择，双击可打开图片进行浏览。下方应存在“多选”、“修改”（修改照片的名称和编号，仅单选可用）、“删除”、“上传”（功能同上文插入图片中的“上传”按钮）按钮，点击以执行对应图片管理功能。  
# “知识点”的云端上传与下载  
该部分是软件必须拥有的功能！
数据传输的范围为整个“知识点库”文件夹。在设置中，有专门区域来进行云端链接相关设置，包括域名、账号、密码、以及上传与下载按钮。域名、账号、密码信息在链接通过后可选择保存在本地，方便下一次进行数据传输。点击上传按钮可以将本地“知识点库”替换云端“知识点库”，点击下载按钮可以将云端“知识点库”替换本地“知识点库”。云端保存文件应当命名为“时间（具体到秒）+账号+知识点库文件”，存储在“账号+知识点库”文件夹中。
