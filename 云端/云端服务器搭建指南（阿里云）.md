## 一、购买阿里云服务器

### 1. 打开阿里云官网

在浏览器中打开 **https://www.aliyun.com**

### 2. 注册/登录账号

- 如果没有阿里云账号，点击右上角「免费注册」
- 支持手机号、支付宝等方式注册

### 3. 购买ECS云服务器

1. 点击顶部导航栏的「产品」→「弹性计算」→「云服务器 ECS」
2. 点击「立即购买」

### 4. 推荐配置（入门级，够用）

| 配置项 | 推荐选择 | 说明 |
|--------|----------|------|
| **付费方式** | 包年包月 | 长期使用更划算 |
| **地域** | 离你最近的 | 如：华东1（杭州） |
| **实例规格** | 2 vCPU / 2 GiB | 入门级够用 |
| **镜像** | Ubuntu 22.04 | 推荐Linux系统 |
| **系统盘** | 40 GB ESSD云盘 | 存文件足够 |
| **带宽** | 按量计费 1Mbps | 够用，超出按量 |

> 💰 **费用参考**：以上配置约 **60-100元/月**。新用户常有优惠，有时可低至 **30-50元/月**。

### 5. 设置登录密码

- 在购买页面设置 root 密码（务必记住！）
- 密码需要包含大写字母、小写字母、数字和特殊字符

### 6. 完成购买

确认订单并支付，等待几分钟服务器即创建完成。

## 二、连接到你的服务器

### 方法一：使用阿里云控制台（推荐新手）

1. 登录阿里云控制台
2. 进入「云服务器 ECS」→「实例」
3. 找到你的服务器，点击「远程连接」
4. 选择「Workbench远程连接」
5. 输入用户名 `root` 和你设置的密码
6. 点击确定即可连接

### 方法二：使用电脑终端

**Windows用户：**
1. 按 `Win + R`，输入 `cmd`，回车
2. 输入命令（替换为你的服务器公网IP）：
   ```
   ssh root@你的服务器公网IP
   ```
3. 输入密码（输入时不显示，这是正常的）
4. 回车登录

**Mac用户：**
1. 打开「终端」应用
2. 输入：`ssh root@你的服务器公网IP`
3. 输入密码回车

> 📍 **查看公网IP**：在阿里云控制台 → ECS实例列表，可以看到「公网IP」一栏。

## 四、部署云同步服务

### 1. 创建服务目录

```bash
mkdir -p /opt/knowledge-sea-server
mkdir -p /opt/knowledge-sea-server/uploads
mkdir -p /opt/knowledge-sea-server/data
cd /opt/knowledge-sea-server
```

### 2. 创建服务器端程序

创建 `server.js` 文件：

```bash
nano server.js
```

将以下内容粘贴进去（在终端中按 `Ctrl+Shift+V` 粘贴）：

```javascript
const http = require('http');
const fs = require('fs');
const path = require('path');
const url = require('url');
const crypto = require('crypto');

const PORT = 3456;
const UPLOAD_DIR = path.join(__dirname, 'uploads');
const DATA_DIR = path.join(__dirname, 'data');
const USERS_FILE = path.join(DATA_DIR, 'users.json');

// 确保目录存在
[UPLOAD_DIR, DATA_DIR].forEach(d => {
  if (!fs.existsSync(d)) fs.mkdirSync(d, { recursive: true });
});

// 初始化用户数据
// 可通过环境变量 CLOUD_USERNAME / CLOUD_PASSWORD 指定初始账号；
// 未指定密码时自动生成随机密码并打印到启动日志。
if (!fs.existsSync(USERS_FILE)) {
  const username = process.env.CLOUD_USERNAME || 'admin';
  const password = process.env.CLOUD_PASSWORD || crypto.randomBytes(12).toString('hex');
  const dir = `${username}_知识库`;
  fs.writeFileSync(USERS_FILE, JSON.stringify({
    users: [ { username, password, dir } ]
  }, null, 2));
  console.log('==============================================');
  console.log('已创建初始账号（请立即修改密码）');
  console.log('  用户名: ' + username);
  console.log('  密码:   ' + password);
  console.log('  用户数据文件: ' + USERS_FILE);
  console.log('==============================================');
}

// 验证用户
function authUser(req) {
  const authHeader = req.headers['authorization'];
  if (!authHeader || !authHeader.startsWith('Basic ')) return null;
  const base64 = authHeader.substring(6);
  const [username, password] = Buffer.from(base64, 'base64').toString().split(':');
  const data = JSON.parse(fs.readFileSync(USERS_FILE, 'utf-8'));
  const user = data.users.find(u => u.username === username && u.password === password);
  return user || null;
}

// ICP 备案号
const ICP = '辽ICP备2026015611号-1';

// 首页 HTML
function getHomePage() {
  return `<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>知识之海 · 云端</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: -apple-system, "Microsoft YaHei", sans-serif; background: #f0f4f8; min-height: 100vh; display: flex; flex-direction: column; }
.container { flex: 1; display: flex; flex-direction: column; align-items: center; justify-content: center; padding: 40px 20px; }
.card { background: #fff; border-radius: 16px; box-shadow: 0 4px 24px rgba(0,0,0,0.08); padding: 48px 40px; max-width: 520px; width: 100%; text-align: center; }
.icon { font-size: 64px; margin-bottom: 16px; }
h1 { font-size: 28px; color: #1a2332; margin-bottom: 8px; }
.sub { color: #8a9bb0; font-size: 14px; margin-bottom: 32px; }
.status { color: #10b981; font-size: 14px; margin-bottom: 20px; }
.files { text-align: left; border-top: 1px solid #e8ecf0; padding-top: 20px; margin-top: 20px; color: #5a6d80; font-size: 14px; line-height: 1.8; }
.files a { display: block; padding: 10px 12px; color: #3b82f6; text-decoration: none; border-radius: 8px; font-size: 14px; }
.files a:hover { background: #eff6ff; }
.footer { text-align: center; padding: 20px; color: #8a9bb0; font-size: 12px; border-top: 1px solid #e8ecf0; }
.footer a { color: #8a9bb0; text-decoration: none; }
.footer a:hover { text-decoration: underline; }
</style>
</head>
<body>
<div class="container">
  <div class="card">
    <div class="icon">🌊</div>
    <h1>知识之海 · 云端</h1>
    <p class="sub">知识之海 云端存储节点</p>
    <div class="status" id="status">正在检测服务状态...</div>
    <div class="files">
      <p>备份文件的上传、下载与查看请在「知识之海」软件内操作：设置 → 云端同步。</p>
    </div>
  </div>
</div>
<div class="footer">
  <a href="https://beian.miit.gov.cn/" target="_blank">${ICP}</a>
</div>
<script>
fetch('/transfer/api/ping')
  .then(r => r.json())
  .then(d => { document.getElementById('status').textContent = '✅ 服务运行正常 · ' + (d.time || ''); })
  .catch(() => { document.getElementById('status').textContent = '⚠️ 无法连接云端服务'; });
</script>
</body>
</html>`;

// 创建服务器
const server = http.createServer((req, res) => {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE, OPTIONS');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type, Authorization');

  if (req.method === 'OPTIONS') {
    res.writeHead(200);
    res.end();
    return;
  }

  const parsedUrl = url.parse(req.url, true);
  const pathname = parsedUrl.pathname;

  // 首页
  if (pathname === '/' && req.method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
    res.end(getHomePage());
    return;
  }

  // === 传输 API ===

  // 认证检查
  if (pathname !== '/transfer/api/ping') {
    const user = authUser(req);
    if (!user) {
      res.writeHead(401, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ error: '认证失败' }));
      return;
    }
    req.user = user;
  }

  try {
    // 上传
    if (pathname === '/transfer/api/upload' && req.method === 'POST') {
      let filename = `backup_${Date.now()}.zip`;
      if (parsedUrl.query.name) {
        filename = Buffer.from(decodeURIComponent(parsedUrl.query.name), 'base64').toString('utf-8');
      }
      const userDir = path.join(UPLOAD_DIR, req.user.dir);
      if (!fs.existsSync(userDir)) fs.mkdirSync(userDir, { recursive: true });
      const destPath = path.join(userDir, filename);

      const chunks = [];
      req.on('data', chunk => chunks.push(chunk));
      req.on('end', () => {
        const buffer = Buffer.concat(chunks);
        fs.writeFileSync(destPath, buffer);
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ success: true, filename }));
      });
      return;
    }

    // 文件列表
    if (pathname === '/transfer/api/list' && req.method === 'GET') {
      const userDir = path.join(UPLOAD_DIR, req.user.dir);
      if (!fs.existsSync(userDir)) {
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ files: [] }));
        return;
      }
      const files = fs.readdirSync(userDir).sort((a, b) => b.localeCompare(a));
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ files }));
      return;
    }

    // 下载
    if (pathname.startsWith('/transfer/api/download/') && req.method === 'GET') {
      const filename = decodeURIComponent(pathname.replace('/transfer/api/download/', ''));
      const userDir = path.join(UPLOAD_DIR, req.user.dir);
      const filePath = path.join(userDir, filename);

      if (!fs.existsSync(filePath)) {
        res.writeHead(404);
        res.end('File not found');
        return;
      }

      const stat = fs.statSync(filePath);
      res.writeHead(200, {
        'Content-Type': 'application/octet-stream',
        'Content-Length': stat.size,
        'Content-Disposition': `attachment; filename="${encodeURIComponent(filename)}"`
      });
      fs.createReadStream(filePath).pipe(res);
      return;
    }

    // 健康检查
    if (pathname === '/transfer/api/ping') {
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ status: 'ok', time: new Date().toISOString() }));
      return;
    }

    // 404
    res.writeHead(404, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ error: 'Not found' }));
  } catch (err) {
    res.writeHead(500, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ error: err.message }));
  }
});

server.listen(PORT, () => {
  console.log('知识之海 云端服务已启动，端口：' + PORT);
  console.log('上传目录：' + UPLOAD_DIR);
  console.log('用户配置：' + USERS_FILE);
});
```

保存文件：按 `Ctrl+X`，然后按 `Y`，再按 `Enter`。

### 3. 安装 PM2（服务进程管理）

```bash
npm install -g pm2
```

### 4. 启动服务

```bash
cd /opt/knowledge-sea-server
pm2 start server.js --name knowledge-sea
pm2 save
pm2 startup
```

按照屏幕提示执行 `pm2 startup` 输出的命令，这样服务器重启后服务会自动启动。

### 5. 配置 Nginx 反向代理

创建 Nginx 配置：

```bash
nano /etc/nginx/sites-available/knowledge-sea
```

粘贴以下内容（**将 `your-domain.com` 替换为你的域名**）：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    client_max_body_size 500M;

    location / {
        proxy_pass http://127.0.0.1:3456;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 120s;
    }
}
```

启用配置：

```bash
ln -sf /etc/nginx/sites-available/knowledge-sea /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl restart nginx
```

### 4.5 配置 HTTPS（SSL证书）

```bash
# 安装 certbot
apt install -y certbot python3-certbot-nginx

# 申请并自动配置证书（替换为你的域名）
certbot --nginx -d your-domain.com -d www.your-domain.com

# 设置自动续期
echo "0 3 * * * certbot renew --quiet" | crontab -
```

> ⚠️ 域名必须已备案才能申请免费 SSL 证书。

## 五、软件配置

### 1. 开放防火墙端口

在阿里云控制台中：
1. 进入「云服务器 ECS」→「实例」→ 点击你的服务器
2. 点击「安全组」标签
3. 点击安全组ID进入详情
4. 点击「手动添加」安全组规则：

| 方向 | 端口范围 | 授权对象 | 说明 |
|------|----------|----------|------|
| 入方向 | 80/80 | 0.0.0.0/0 | HTTP访问 |
| 入方向 | 443/443 | 0.0.0.0/0 | HTTPS访问（可选） |
| 入方向 | 22/22 | 0.0.0.0/0 | SSH远程连接 |

### 2. （可选）绑定域名

如果你有自己的域名：

1. 在域名服务商处，添加一条 **A记录**：
   - 主机记录：`@`（或 `knowledge` 等子域名）
   - 记录类型：`A`
   - 记录值：你的服务器公网IP

2. 将 Nginx 配置中的 `server_name` 改为你的域名

### 3. （推荐）配置 HTTPS

```bash
# 安装 certbot
apt install -y certbot python3-certbot-nginx

# 获取免费SSL证书（需要有域名）
certbot --nginx -d your-domain.com
```

## 六、在软件中配置云端同步

1. 打开 The Sea of Knowledge 软件
2. 点击右上角 ⚙ 设置按钮
3. 在「云端同步设置」区域填写：

| 设置项 | 填写内容 |
|--------|----------|
| **服务器域名** | `http://你的服务器公网IP` 或 `https://你的域名` |
| **账号** | 首次启动时由日志打印（默认 `admin`） |
| **密码** | 首次启动时由日志打印（自动生成的随机密码） |

4. 勾选「记住登录信息」
5. 点击「📤 上传到云端」即可将本地知识点库备份到服务器
6. 在另一台电脑上，点击「📥 从云端下载」即可同步知识点

### 修改默认密码

连接到服务器，编辑用户文件：

```bash
nano /opt/knowledge-sea-server/data/users.json
```

修改 `password` 字段后保存，然后重启服务：

```bash
pm2 restart knowledge-sea
```

## 七、个人云盘功能

你的服务器还可以充当个人云盘！推荐使用 **Nextcloud** 或 **FileBrowser**。

### 方案：安装 FileBrowser（简单轻量）

```bash
# 下载 FileBrowser
curl -fsSL https://raw.githubusercontent.com/filebrowser/get/master/get.sh | bash

# 创建配置目录
mkdir -p /opt/filebrowser
cd /opt/filebrowser

# 初始化配置
filebrowser config init
filebrowser users add admin 你的密码 --perm.admin
filebrowser config set --root /opt

# 创建 systemd 服务
cat > /etc/systemd/system/filebrowser.service << 'EOF'
[Unit]
Description=File Browser
After=network.target

[Service]
ExecStart=/usr/local/bin/filebrowser -a 0.0.0.0 -p 8080 -r /opt
Restart=always

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable filebrowser
systemctl start filebrowser
```

然后在安全组中开放 **8080** 端口，访问 `http://你的服务器IP:8080` 即可使用网页版文件管理器。

你也可以用 Nginx 反代它：

```nginx
# 在 /etc/nginx/sites-available/knowledge-sea 中添加：
server {
    listen 80;
    server_name files.your-domain.com;  # 使用子域名

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 八、常见问题

### Q: 上传/下载失败怎么办？
1. 检查服务器是否正常运行：`pm2 status`
2. 检查Nginx是否运行：`systemctl status nginx`
3. 检查安全组是否开放了80端口
4. 查看服务日志：`pm2 logs knowledge-sea`

### Q: 忘记服务器密码怎么办？
在阿里云控制台 → ECS实例 → 更多 → 重置实例密码

### Q: 如何增加存储空间？
在阿里云控制台中购买云盘并挂载到服务器。

### Q: 可以进行增量同步吗？
当前版本采用全量同步（整个知识点库打包上传/下载）。增量同步将在后续版本支持。

### Q: 多人可以共用服务器吗？
可以！在 `data/users.json` 中添加多个用户，每个用户有独立的知识点库文件夹，互不干扰。
