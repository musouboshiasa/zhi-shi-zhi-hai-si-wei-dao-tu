# 知识之海 (The Sea of Knowledge)

> 🌊 轻量级知识管理工具：用「知识点」组织知识，用思维导图看清它们之间的关联，随时随地云端备份。

一个面向个人学习、备考的本地优先知识管理软件。把零散的知识写成一条条「知识点」，用「前相关 / 后相关」把它们串成知识网络，再以思维导图直观展示。数据以纯文本 Markdown 文件保存在本地，可随时备份，也可自建服务器同步。

## ✨ 功能

- **知识点管理** — 创建、查看、编辑、删除知识点；正文支持 Markdown 与 LaTeX 数学公式（KaTeX 渲染）
- **双向关联** — 每个知识点可设置「前相关知识」「后相关知识」，系统自动建立反向链接
- **思维导图** — 三种模式可视化知识网络，支持节点拖拽、红绿蓝画笔上色、缩放平移，高分屏下清晰渲染：
  - 🔗 后延式 — 沿后相关方向展开
  - 🔄 周围式 — 以选中知识点为中心、前后各 N 层展开
  - 🎛 自由式 — 自定义前后层数
- **图片管理** — 知识点可插入图片；独立图片管理面板支持上传、搜索、多选、重命名、删除
- **云端同步** — 上传/下载整个知识库（Basic Auth）；下载前自动本地备份，认证失败有明确提示
- **多用户登录** — 每个账号有独立的存储空间；首个账号为管理员，可添加并管理其他账号，密码加盐哈希存储
- **搜索** — 首页与顶栏均可按编号或名称即时搜索
- **个性化** — 自定义电子签名与字体、可调刷新率

## 🚀 快速开始

### 前置要求

- [Node.js](https://nodejs.org/) ≥ 16

### 安装与启动

```bash
git clone https://github.com/musouboshiasa/zhi-shi-zhi-hai-si-wei-dao-tu.git
cd zhi-shi-zhi-hai-si-wei-dao-tu
npm install
node server.js
```

浏览器打开 `http://localhost:3000`（Windows 下也可双击 `启动软件.bat`）。

首次打开会引导你**创建管理员账号**，之后即可登录使用；每个账号拥有独立的知识库，互不干扰。

### 部署到服务器（网页版）

- **独立域名**：见 `deploy/nginx.conf`
- **子路径（与现有网站/网盘共存）**：见 `deploy/nginx-子路径.conf`
- 完整步骤见 `deploy/服务器部署指南.md`

## 📖 使用指南

### 创建知识点

点击「新建知识点」，填写编号（支持层级编号，如 `1-2-1`）、名称（可含中文与 `/` 等特殊字符）和 Markdown 正文。

### 编辑关系

- **前相关知识** — 指向当前知识点的基础 / 前期知识
- **后相关知识** — 当前知识点引出的后续 / 扩展知识

关联规则：若 A 是 B 的前相关知识，则 B 自动成为 A 的后相关知识。

### 思维导图

在知识点查看页点击「思维导图」，选择模式即可；导图页内也可直接「新建知识点」。

### 云端同步

1. 自建云端中转服务（见 `deploy/云端中转服务/server.js` 与 `云端/云端服务器搭建指南（阿里云）.md`）
2. 在软件「设置 → 云端同步」中填写服务器域名、账号、密码
3. 点击「上传到云端」备份 / 「从云端下载」恢复

## 💻 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Node.js + Express |
| 前端 | 原生 HTML/CSS/JS + Canvas（高分屏适配） |
| 公式 | KaTeX (CDN) |
| Markdown | marked.js (CDN) |
| 打包 | archiver + extract-zip |

## 📁 项目结构

```
.
├── server.js                  # 后端主程序（API + 静态服务 + 云端同步）
├── public/                    # 前端（index.html / css / js）
│   ├── js/app.js              # 页面逻辑
│   └── js/mindmap.js          # 思维导图渲染
├── 知识点库/用户/<账号>/       # 各账号独立的知识点数据（Markdown + 图片 + 索引）
├── data/                       # 账号与密钥（已 .gitignore 忽略）
├── 云端/                       # 云端配置与阿里云部署指南
├── deploy/                    # 部署脚本、Nginx 配置、systemd 单元、云端中转服务
├── src/kp_parser.c            # C 语言知识点解析器（可选独立工具）
└── 启动软件.bat               # Windows 一键启动
```

## 📁 知识点文件格式

知识点文件保存在 `知识点库/储存文件/`，文件名格式：`编号：名称.md`。每个文件结构：

```
（（编号区））
编号
（（名称区））
名称
（（正文区））
Markdown 正文
（（前相关区））
- 编号：关系：名称
（（后相关区））
- 编号：关系：名称
（（结束））
```

## 🔒 安全说明

- 图片接口与云端下载接口均已做路径穿越防护
- 云端中转服务不再内置默认密码：首次启动自动生成随机密码（见启动日志），或通过 `CLOUD_USERNAME` / `CLOUD_PASSWORD` 环境变量指定
- 云端密码仅在勾选「记住登录信息」时才会写入本地配置
