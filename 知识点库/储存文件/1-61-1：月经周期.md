# 激素周期  
| 周期阶段 | GnRH/FSH（卵泡刺激素） | LH（促黄体生成素） | 雌激素 (E₂) | 孕酮（内源孕激素） | 抑制素 |
|---------|----------|----|------------|------|--------|
| 卵泡早期 | FSH稍↑ | 低 | 极低 | 极低 | 低 |
| 卵泡晚期 | FSH↓（负反馈） | 低→升 | 迅速↑，达排卵前峰 | 极低 | 抑制素B↑ |
| 排卵期 | FSH小峰 | **LH峰** | 峰后急降 | 开始↑ | - |
| 黄体期 | 最低（负反馈） | 最低 | 第二峰（低于前期） | **高峰** | 抑制素A↑ |
| 月经期 | FSH开始↑ | 低 | 极低 | 极低 | 极低 |  
  
# 激素作用  
- GnRH（促性腺激素释放激素）：低频脉冲倾向于促进 FSH 分泌，高频脉冲倾向于促进 LH 分泌。  
- FSH（卵泡刺激素）：  
1.促进卵泡生长和募集：在卵泡早期，FSH 升高，刺激卵巢中一批窦卵泡发育。   
2.诱导颗粒细胞增生，并促进芳香化酶活性，使卵泡膜细胞产生的雄激素转化为雌激素（E₂）。  
3.诱导LH受体：使优势卵泡后期能响应LH峰。  
4.刺激分泌抑制素 B，后者负反馈抑制垂体分泌 FSH（不直接抑制 LH），实现单卵泡选择。  
- 雌激素：  
| 功能 | 机制与意义 |
|------|------------|
| **增殖内膜、宫颈黏液稀化、输卵管活动增加** | 为精子运输及受精卵着床做准备 |
| **负反馈控制FSH** | 参与优势卵泡选择和单卵泡发育（与抑制素共同） |
| **培养颗粒细胞的LH受体** | 让成熟卵泡能够响应LH峰而排卵和黄体化 |
| **正反馈诱发排卵前LH峰** | 雌激素峰值是触发排卵的**关键定时事件** |
| **黄体期与孕酮协同** | 维持分泌期内膜，保证营养，支持早期胚胎着床 |
| **撤退引发月经** | 雌孕激素同时撤退是子宫内膜完整脱落的必要条件 |  
  
- 孕酮：  
| 功能 | 具体作用 | 临床联系 |
|------|----------|----------|
| **内膜转化** | 促进增殖期内膜转为分泌期，准备着床 | 黄体功能不足（孕酮不足）可致分泌期不良、不孕或早孕流产 |
| **子宫肌镇静** | 降低收缩性，保护胚胎 | 孕激素类药物可用于安胎（但需对应指征） |
| **宫颈封闭** | 黏液变稠形成黏液栓 | 孕激素避孕药的机制之一（改变宫颈黏液） |
| **体温升高** | 基础体温升高0.3-0.5℃ | 简便的排卵监测方法 |
| **中枢负反馈** | 强力抑制GnRH、FSH、LH，阻断新卵泡生长 | 孕激素单独或合用可用于抑制排卵（激素避孕） |
| **撤退引发月经** | 激素骤降导致内膜规律崩解脱落 | 孕酮撤退试验用于诊断闭经类型 |
| **乳腺腺泡发育** | 与雌激素协同完成乳腺构建 | 乳房胀痛为常见黄体期症状 |  
  
- 抑制素：  
| 功能维度 | 具体作用 | 关键特点 |
|----------|----------|----------|
| **内分泌作用** | **选择性抑制垂体FSH的合成与分泌**，几乎不影响LH基础分泌 | 经典的负反馈调节，维持FSH水平的精细控制 |
| **卵泡发生与选择** | 抑制素B参与抑制FSH，仅在优势卵泡能存活的水平，促成单卵泡排卵 | 与雌二醇协同，是优势卵泡选择的主动信号 |
| **卵巢储备指标** | 抑制素B水平直接反映窦卵泡的数量与质量 | 比FSH更早出现变化，是评估卵巢老化的敏感指标 |
| **黄体期抑制** | 抑制素A与孕酮共同强效抑制FSH，防止新卵泡生长 | 与孕酮同步，是黄体功能的标志物之一 |
| **产前筛查** | 抑制素A是中孕期唐氏筛查四联指标之一 | 升高提示某些染色体异常风险 |
| **局部调控** | 在卵巢内拮抗激活素，调控颗粒细胞增殖与凋亡 | 属于自分泌/旁分泌，影响卵泡闭锁 |
