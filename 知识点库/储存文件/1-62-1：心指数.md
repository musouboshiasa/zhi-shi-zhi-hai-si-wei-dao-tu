（（正文区））
-   **定义**：心指数是指**每平方米体表面积每分钟的心输出量**。
-   **公式**：
    \[
    \text{心指数 (CI)} = \frac{\text{心输出量 (CO)}}{\text{体表面积 (BSA)}}
    \]  
  
- **范围**：  
| 心指数范围 [L/(min·m²)] | 临床意义 | 常见情景 |
| :--- | :--- | :--- |
| **> 3.5** | 高动力循环状态或高排血量心力衰竭 | 发热、甲亢、严重贫血、早期脓毒症、维生素B1缺乏性心脏病 |
| **2.2 - 3.5** | **正常范围** | 正常健康成人静息状态 |
| **1.8 - 2.2** | **心输出量轻度下降** | 可能需要临床干预的代偿性心力衰竭或低血容量 |
| **< 1.8** | **心源性休克或严重心力衰竭** | 心肌大面积梗死、爆发性心肌炎、终末期心衰 |
