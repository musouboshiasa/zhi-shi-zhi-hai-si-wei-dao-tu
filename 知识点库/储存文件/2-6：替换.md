- 通配符  
**word：**  
| 通配符 | 作用 | 示例（查找内容） | 可能找到的文本 |
|--------|------|------------------|----------------|
| `?` | 任意**单个**字符 | `s?t` | sat, set, sit |
| `*` | 任意**多个**字符（含0个） | `s*d` | sad, started, seed |
| `[ ]` | 指定字符集中的**任意一个** | `[scl]it` | sit, cit, lit |
| `[ - ]` | 指定范围内的**任意一个**字符 | `[a-m]end` | bend, fend, lend, mend |
| `[! ]` | 排除指定字符，**任意一个不在集合内**的字符 | `[!a-m]end` | rend, send, tend (不含a-m开头的) |
| `<` | 单词的**开头** | `<(some)` | something, somebody |
| `>` | 单词的**结尾** | `(one)>` | someone, anyone, phone |
| `@` | 前一字符出现**一次或多次** | `lo@t` | lot, loot, loooot |
| `{n}` | 前一字符**恰好出现 n 次** | `lo{2}t` | look（o出现了2次？举例：`lo{2}t` 匹配 loot，o两个） |
| `{n,}` | 前一字符**至少出现 n 次** | `lo{2,}t` | loot, looot |
| `{n,m}` | 前一字符出现 **n 到 m 次** | `10{1,3}` | 10, 100, 1000 |
| `*` 和 `?` 的组合 | 限定长度或格式 | `[0-9]{3}-[0-9]{4}` | 010-1234 之类的号码格式 |
| `( )` | 分组（用于替换时重新排列） | `(John) (Doe)` 替换为 `\2, \1` | 找到 "John Doe"，替换成 "Doe, John" |
| `\n` | 替换时引用第 n 个分组 | `\1` 代表第一个括号内容 | 如上 |  
| `\ ` | 转义字符，查找其本身 | `"\[ \]"` 只找 "[]"，而不会把[]当作通配符 | |
  
**excel：**  
| 通配符 | 含义 | 示例 |
|--------|------|------|
| `?` | 任意单个字符 | `"Sm?th"` 可找到 Smith 和 Smyth |
| `*` | 任意长度的字符序列 | `"*east"` 可找到 Northeast, Southeast, east |
| `~` | 转义字符，查找 `?`、`*` 或 `~` 本身 | `"What~?"` 只找 "What?"，而不会把问号当作通配符 |
