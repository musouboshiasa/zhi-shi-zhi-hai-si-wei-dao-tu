在生理学和临床诊断中，呼吸功能主要通过两大维度来评估：一是**肺通气功能**（机械动力学），二是**肺泡气体交换功能**（血气分析）。以下是医学生需要掌握的核心指标及其正常值和意义。

---

### 一、肺通气的容积与容量指标（肺功能检查）

这些指标反映了气道的通畅性、呼吸肌力量及肺的顺应性。

| 分类 | 指标（缩写） | 定义与正常成人参考值 | 临床要点 |
| :--- | :--- | :--- | :--- |
| **基础容积** | **潮气量 (TV/VT)** | 平静呼吸每次吸入或呼出的气量，约 **500 mL** | 运动或高热时增加，呼吸中枢抑制时减少 |
| | **补吸气量 (IRV)** | 平静吸气末再尽力吸气所能吸入的气量，约 **1500-2000 mL** | 反映吸气储备，限制性肺病时减少 |
| | **补呼气量 (ERV)** | 平静呼气末再尽力呼气所能呼出的气量，约 **900-1200 mL** | 肥胖、腹水时减少 |
| | **残气量 (RV)** | 最大呼气末残留在肺内的气量，约 **1000-1500 mL** | 不能由肺量计测出；阻塞性肺病时显著增加（气体陷闭） |
| **基础容量** | **肺活量 (VC)** | 最大吸气后能呼出的最大气量 (TV+IRV+ERV)<br>男约 **3500 mL**，女约 **2500 mL** | 反映肺总代偿能力；降低见于限制性病变、严重阻塞 |
| | **功能残气量 (FRC)** | 平静呼气末留在肺内的气量 (ERV+RV)<br>约 **2400 mL** | 生理上起缓冲肺泡气体分压的作用；增加见于肺气肿，减少见于间质病变 |
| | **肺总量 (TLC)** | 肺所能容纳的最大气量 (VC+RV)<br>男约 **5000 mL**，女约 **3500 mL** | 提高见于肺气肿，降低见于限制性肺病（如肺纤维化、胸廓畸形） |

---

### 二、动态通气功能指标（快速呼吸力学测定）

这部分是区分**阻塞性**与**限制性**通气功能障碍的关键。

| 指标（缩写） | 定义与正常值 | 临床解读核心 |
| :--- | :--- | :--- |
| **用力肺活量 (FVC)** | 最大吸气后以最快速度用力呼出的最大气量，正常人FVC≈VC | 限制性病变：FVC明显降低<br>阻塞性病变：FVC可正常或轻度降低 |
| **第一秒用力呼气容积 (FEV1)** | FVC测试中第一秒呼出的气量，正常FEV1/FVC比值 **≥ 70%**（或FEV1占预计值% > 80%） | **阻塞性通气障碍**：FEV1显著下降，FEV1/FVC < 70%<br>**限制性通气障碍**：FEV1与FVC等比例下降，比值正常或升高 |
| **峰值呼气流速 (PEF)** | 用力呼气时的瞬间最高流速 | 主要反映大气道功能及呼吸肌力量，常用于哮喘的自我监测 |
| **最大通气量 (MVV)** | 一分钟内以最大幅度和最快频率呼吸所能呼出的总量 | 反映通气储备，手术耐受力评估，严重肺病时下降 |

**小气道功能早期指标：** 最大呼气中段流量（MMEF，即FVC在25%-75%间的平均流速）在FEV1正常时即可出现降低，是小气道阻塞的敏感信号。

---

### 三、气体交换与血气分析指标（评估换气功能）

这组指标直接反映呼吸的终末功能——为血液供氧、排出二氧化碳。

| 指标（缩写） | 正常参考值（动脉血） | 临床意义 |
| :--- | :--- | :--- |
| **动脉血氧分压 (PaO2)** | **80-100 mmHg** | 直接反映肺换气功能和吸入氧浓度；低下为低氧血症 |
| **动脉血二氧化碳分压 (PaCO2)** | **35-45 mmHg** | 衡量肺泡通气的**金标准**。PaCO2 > 45 mmHg为通气不足（如慢阻肺加重）；PaCO2 < 35 mmHg为通气过度（如癔症、高热气促） |
| **动脉血氧饱和度 (SaO2)** | **95%-98%** | 氧合血红蛋白的比例，受PaO2、体温、pH影响。低于90%提示严重缺氧 |
| **肺泡-动脉氧分压差 (A-aDO2)** | 吸空气时 **5-15 mmHg**（随年龄增大） | **鉴别低氧原因关键**：正常+PaCO2升高=单纯通气不足；异常升高=换气障碍（如肺栓塞、肺水肿） |
| **氧合指数 (PaO2/FiO2)** | **400-500 mmHg** | 急性呼吸窘迫综合征（ARDS）分层的核心依据，< 300 mmHg为急性肺损伤，< 200 mmHg为ARDS |

---

### 四、呼吸动力与阻抗指标（呼吸力学监测）

多见于ICU和科研，简单了解：
-   **肺顺应性**（C = ΔV/ΔP）：分为静态和动态。肺纤维化时变硬（C降低），肺气肿时弹性回缩力丧失（C增加）。
-   **气道阻力**（Raw）：反映气道通畅度，哮喘发作时阻力显著上升。

---

**诊断思路总结：**
拿到一张肺功能报告，先看FEV1/FVC比值判断有无阻塞；再看FVC是否有降低判断有无限制；最后结合血气分析的PaO2和PaCO2评估气体交换和通气状况。
