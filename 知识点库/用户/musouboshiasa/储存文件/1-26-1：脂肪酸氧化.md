# 活化（形成脂肪酸-CoA）  
脂肪酸 + CoA + ATP → 脂酰-CoA + AMP + PPi  
# 转运进入线粒体  
# β-氧化循环（每轮四步）（形成乙酰-CoA）
① 脱氢：脂酰-CoA → 反式-Δ²-烯脂酰-CoA（FAD→FADH₂）  

② 加水：生成 L-β-羟脂酰-CoA

③ 再脱氢：生成 β-酮脂酰-CoA（NAD⁺→NADH）

④ 硫解：硫解酶裂解下1分子乙酰-CoA，脂酰-CoA缩短2个碳。  
# 产物去向  
- 乙酰-CoA：进入三羧酸循环彻底氧化，或在肝脏生成酮体。
- FADH₂、NADH：进入呼吸链氧化磷酸化
