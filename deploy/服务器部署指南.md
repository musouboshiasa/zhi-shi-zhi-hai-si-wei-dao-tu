# 知识之海 子路径部署指南（musouboshiasa.com/ruanjian）

> 将"知识之海"部署到你的服务器，手机、平板、电脑都能通过
> **https://musouboshiasa.com/ruanjian/** 访问，与服务器上现有的网站、网盘互不干扰。

## 📌 部署原理（先看懂再动手）

你的服务器上已经有网站/网盘在运行（占用了 80/443 端口和主域名）。
知识之海部署后走 **子路径**：`https://musouboshiasa.com/ruanjian/`

```
浏览器 → https://musouboshiasa.com/ruanjian/xxx
                ↓ (Nginx)
         /ruanjian/ 路径 → 转发给知识之海 (本机3000端口)
         /            → 还是原来的网站/网盘
```

**你只需要做一件事**：在现有 Nginx 配置里加一小段"反向代理"规则。

---

## 第 1 步：把项目文件传到服务器

用 WinSCP（或宝塔面板的文件管理器）把以下内容上传到 `/opt/knowledge-sea/`：

| 文件/文件夹 | 说明 |
|---|---|
| `server.js` | 后端程序 |
| `package.json`、`package-lock.json` | 依赖清单 |
| `public/` | 网页前端 |
| `deploy/` | 部署文件 |
| `知识点库/` | 你的知识数据（可后续再传） |

## 第 2 步：安装 Node.js + 启动服务（服务器上执行）

SSH 登录服务器后执行：

```bash
cd /opt/knowledge-sea
npm install --production
cp deploy/knowledge-sea.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable knowledge-sea
systemctl start knowledge-sea
systemctl status knowledge-sea    # 看到 running 即成功
```

验证：执行 `curl http://127.0.0.1:3000` 能看到网页内容。

> 如果提示 npm 不存在，先执行：
> `curl -fsSL https://mirrors.aliyun.com/nodesource/setup_20.x | bash - && apt-get install -y nodejs`

## 第 3 步：配置 Nginx 反向代理（核心步骤）

### 如果用的是宝塔面板（推荐方式，最简单）

1. 登录宝塔面板 → 网站 → 找到 musouboshiasa.com 的站点
2. 点"反向代理" → 添加反向代理：
   - 名称：`knowledge-sea`
   - 目标 URL：`http://127.0.0.1:3000`
   - 发送域名：留空（默认）
3. 再点"配置文件"（或"伪静态"旁的编辑按钮），在 `server { }` 块内**最前面**加：

```nginx
location = /ruanjian {
    return 301 /ruanjian/;
}
```

4. 保存后宝塔会自动 reload Nginx

> 💡 宝塔的"反向代理"功能默认是把整个站点反代到目标，**我们需要的是子路径反代**。
> 所以更保险的做法是：只编辑"配置文件"，手动加下面这段（第 2 种方法），而不是用宝塔自带的反代功能。

### 手动编辑 Nginx 配置（通用）

1. 找到站点配置文件：
   - 宝塔：`/www/server/panel/vhost/nginx/站点名.conf`
   - 手动 Nginx：`/etc/nginx/sites-enabled/xxx.conf`
2. 在对应 server 块的 **location / { } 之前** 加入：

```nginx
# 无斜杠访问自动补斜杠
location = /ruanjian {
    return 301 /ruanjian/;
}

# 知识之海反向代理
location /ruanjian/ {
    proxy_pass http://127.0.0.1:3000/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 300s;
    client_max_body_size 50M;
}
```

3. 保存后验证并生效：
```bash
nginx -t && systemctl reload nginx
```

## 🛠 常见问题

### Q: 访问 /ruanjian/ 显示 404 或空白
- 确认反向代理配置在**正确的 server 块**里
- 确认 Node 服务在运行：`systemctl status knowledge-sea`

### Q: 样式错乱、没有 CSS
- 说明 base 路径没生效。确认访问的是 `/ruanjian/`（**带尾部斜杠**）

### Q: 图片打不开
- 确认 Nginx 配置里有 `client_max_body_size 50M;`
- 图片存储位置：`/opt/knowledge-sea/知识点库/图片/`

### Q: 上传/下载云端备份
- 软件内置的云端同步功能使用独立配置，网页版同样可用（设置里配置云端地址）

### Q: 如何把本地知识点库搬到服务器
- 用 WinSCP 把本地 `知识点库/` 整个文件夹覆盖到 `/opt/knowledge-sea/知识点库/`
- 然后 `systemctl restart knowledge-sea`

### Q: 域名访问不了 /ruanjian 但主站正常
- 检查宝塔站点配置里是否已有同名的 location 规则冲突
