# 知识之海 网页版部署指南（阿里云 Linux 服务器）

> 本指南手把手教你将"知识之海"部署到你的服务器，让手机、平板、电脑都能通过 `https://musouboshiasa.com` 访问。

## 📋 准备工作

| 需要准备 | 说明 |
|---|---|
| 阿里云 ECS 服务器 | 操作系统选 **Ubuntu 22.04** 或 **Debian 12** |
| 域名 musouboshiasa.com | 已通过实名认证 |
| 电脑上的 SSH 工具 | Windows 自带"终端"或下载 MobaXterm |

---

## 第 1 步：购买服务器（如已有可跳过）

1. 登录 [阿里云控制台](https://ecs.console.aliyun.com/)
2. 创建 ECS 实例：
   - 操作系统：**Ubuntu 22.04 64位**
   - 最低配置：2核 2G（够用）
   - 安全组：放行 **22**（SSH）、**80**（HTTP）、**443**（HTTPS）端口
3. 设置 root 密码，记好

> 💡 如果已经买了服务器，只需确认安全组放行了 80/443 端口。

## 第 2 步：域名解析（如果没做）

1. 登录域名控制台（阿里云域名管理）
2. 找到 musouboshiasa.com → 解析设置
3. 添加两条 **A 记录**：
   | 主机记录 | 记录类型 | 记录值 |
   |---|---|---|
   | @ | A | 你的服务器公网IP |
   | www | A | 你的服务器公网IP |
4. 等 5-10 分钟生效

## 第 3 步：登录服务器

### Windows 自带终端（推荐）
1. 按 `Win + R`，输入 `cmd`，回车
2. 输入以下命令（把 IP 换成你的服务器公网IP）：
   ```
   ssh root@你的服务器IP
   ```
3. 输入密码（输入时不显示，正常）

看到类似 `root@xxx:~#` 的提示符就说明登录成功。

## 第 4 步：上传项目文件

在**自己的电脑**上操作（不是在服务器上）：

### 方法 A：用 WinSCP（图形化，推荐小白）
1. 下载安装 [WinSCP](https://winscp.net/)
2. 连接服务器：主机填服务器IP，用户名 root，密码
3. 在服务器窗口进入 `/opt/`，新建文件夹 `knowledge-sea`
4. 把**本地项目文件夹**里的这些内容拖进去：
   - `server.js`
   - `package.json`
   - `package-lock.json`
   - `public/` 文件夹
   - `知识点库/` 文件夹（**可选**：不带也行，网页版可新建）
   - `deploy/` 文件夹

### 方法 B：用命令（服务器上执行）
先在电脑上把项目打成压缩包，再用下面命令传到服务器：
```bash
# 在服务器上执行（IP 换成你的服务器IP）
scp -r 本地项目路径/* root@你的服务器IP:/opt/knowledge-sea/
```

## 第 5 步：一键部署

在服务器上执行：
```bash
cd /opt/knowledge-sea
bash deploy/deploy.sh
```

脚本会自动完成：
- ✅ 安装 Node.js
- ✅ 安装 Nginx
- ✅ 安装 HTTPS 证书（certbot）
- ✅ 启动软件服务
- ✅ 配置域名访问

## 第 6 步：验证

1. 打开浏览器访问 `https://musouboshiasa.com`
2. 看到"知识之海"首页即部署成功
3. 手机浏览器访问同一网址，应显示适配手机的界面

## 🔧 日常管理命令（在服务器上）

| 操作 | 命令 |
|---|---|
| 查看软件状态 | `systemctl status knowledge-sea` |
| 重启软件 | `systemctl restart knowledge-sea` |
| 查看日志 | `journalctl -u knowledge-sea -n 50` |
| 停止软件 | `systemctl stop knowledge-sea` |
| 重启 Nginx | `systemctl reload nginx` |

## 📱 数据存放位置

- 知识点库存在服务器：`/opt/knowledge-sea/知识点库/`
- **重要**：定期备份，用 WinSCP 把整个 `知识点库` 文件夹下载到电脑

## 🛟 常见问题

### Q: 访问显示"无法访问此网站"
- 检查安全组是否放行 80/443 端口
- 检查域名解析是否生效：电脑上打开 cmd 输入 `ping musouboshiasa.com`

### Q: 证书申请失败
- 确认域名解析已生效后再执行一次：
  ```bash
  certbot --nginx -d musouboshiasa.com -d www.musouboshiasa.com
  ```

### Q: 想更新软件版本
1. 用 WinSCP 把新的 `server.js`、`public/` 等覆盖到 `/opt/knowledge-sea/`
2. 服务器上执行 `systemctl restart knowledge-sea`
