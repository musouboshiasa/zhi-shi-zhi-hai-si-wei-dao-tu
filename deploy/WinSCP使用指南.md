# WinSCP 使用指南（上传文件到服务器）

> WinSCP 是一个图形化文件传输工具，可以像操作"两个文件夹"一样，  
> 把文件从你的电脑传到服务器。**全程鼠标操作，不需要记命令。**



---

## 一、下载安装 WinSCP

1. 打开浏览器，访问官网：**<https://winscp.net>**
2. 点页面上的 **DOWNLOAD**（下载）按钮
3. 下载完成后，双击安装文件（`.exe`）
4. 安装时一路点"下一步/Next"即可，用默认设置
5. 安装完成后桌面上会出现 WinSCP 图标

---

## 二、连接你的服务器

1. **双击桌面 WinSCP 图标**，会弹出登录窗口：
   | 需要填写 | 填什么                          |
   | ---- | ---------------------------- |
   | 文件协议 | `SFTP`（下拉框选择）                |
   | 主机名  | 你的服务器公网 IP（如 `47.100.xx.xx`） |
   | 端口号  | `22`                         |
   | 用户名  | `root`                       |
   | 密码   | 你服务器设置的 root 密码              |
2. 点 **登录** 按钮
3. 第一次连接会弹出提示"是否信任此主机"，点 **是/接受**
4. 登录成功后，你会看到 WinSCP 主界面：
   ```
   ┌──────────────────────────┬──────────────────────────┐
   │   左边：你的电脑文件       │   右边：服务器文件        │
   │   （本地目录）            │   （远程目录）            │
   └──────────────────────────┴──────────────────────────┘
   ```

> 💡 如果连接失败，检查：
>
> - 密码是否正确（注意大小写）
> - 服务器安全组是否放行了 **22 端口**
> - IP 是否填写正确

## 三、上传知识之海项目（核心操作）

### 第 1 步：在服务器上创建文件夹

1. 在 WinSCP 右边（服务器窗口）顶部地址栏输入：`/opt`
2. 回车，进入 `/opt` 目录
3. 点击工具栏的 **新建文件夹** 图标（或右键 → 新建 → 目录）
4. 文件夹名输入：`knowledge-sea`
5. 双击进入这个新文件夹

### 第 2 步：把项目文件拖进去

1. 在 WinSCP 左边（电脑窗口）找到项目文件夹：
   - 通常路径：`C:\Users\你的用户名\WorkBuddy\the sea of knowledge`
2. 进入项目文件夹后，**按住 Ctrl 多选** 这些内容：
   - `server.js`
   - `package.json`
   - `package-lock.json`
   - `public`（文件夹）
   - `deploy`（文件夹）
   - `知识点库`（文件夹，**可选**）
3. **直接拖拽** 到右边的 `/opt/knowledge-sea/` 窗口里
4. 出现传输进度条，等待完成

> 💡 拖拽就是"复制"。拖动时按住 Ctrl 可以保证是复制而不是移动。

### 第 3 步：确认文件到位

上传完成后，右边窗口应该看到：

```
/opt/knowledge-sea/
├── server.js
├── package.json
├── package-lock.json
├── public/
├── deploy/
└── 知识点库/
```

## 四、常用操作

### 1. 把服务器的文件下载到电脑（备份）

- 在右边（服务器）选中文件/文件夹
- 拖拽到左边（电脑）窗口
- 文件就下载到电脑了

### 2. 更新单个文件（比如改过的 server.js）

- 直接拖新的文件覆盖到服务器同名文件
- 弹出"是否覆盖"提示，点 **是**

### 3. 删除服务器上的文件

- 选中文件 → 右键 → **删除**

## 五、配合部署脚本使用

文件上传完成后，回到 SSH 终端（cmd 窗口）执行部署命令：

```bash
cd /opt/knowledge-sea
npm install --production
cp deploy/knowledge-sea.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable knowledge-sea
systemctl start knowledge-sea
```

或者直接执行一键脚本（WinSCP 上传文件时把 deploy 文件夹也传上去）：

```bash
cd /opt/knowledge-sea
bash deploy/deploy.sh
```

## 六、常见问题

| 问题          | 解决方法                            |
| ----------- | ------------------------------- |
| 登录提示"拒绝访问"  | 密码错误，或安全组没放行 22 端口              |
| 连接超时        | 检查服务器 IP 和网络                    |
| 传输很慢        | 文件多属正常；也可把 `知识点库` 打成 zip 再传     |
| 中文文件名乱码     | WinSCP 会话设置里，把"远程文件名编码"改为 UTF-8 |
| 找不到 /opt 目录 | 在地址栏直接输入 /opt 回车                |

---

## 七、安全提醒

- **密码不要告诉别人**，WinSCP 登录时不要点"保存密码"到公用电脑
- 传输完成后可以直接关闭 WinSCP，不影响服务器运行
- 建议定期用 WinSCP 把服务器的 `知识点库` 文件夹下载回电脑备份
